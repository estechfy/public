審査・操作確認

通常の動画再生は無料でサインイン不要です。新規暗号化・カット保存の確認は「FastPlayer → 無料体験・Pro・購入の復元…」から30日体験を取得して開始します。既存の保護動画の再生と暗号化解除は体験終了後も無料です。

確認用のサンプル

FastPlayer用に作成した20秒のH.264/AAC動画です。実写・個人情報・第三者の動画は含みません。再生、暗号化、カット、暗号化解除の確認に利用できます。

確認用MP4を保存

動画保護を確認する

  1. 「動画保護 → Googleにサインイン…」からGoogleの認証画面へ進み、Driveのアプリ専用データへのアクセスを許可します。Apple審査用の認証情報はApp Store Connectの非公開欄で確認してください。
  2. 「動画保護 → ファイルを暗号化…」で保存したサンプルを選びます。原本は残ります。
  3. 完成した .fpv を「ファイル → 開く…」またはドロップで開き、再生、シーク、速度変更、シークバーのプレビューを確認します。
  4. 「動画保護 → 開いている保護動画をカット…」で開始・終了を指定し、残す区間と削る区間を確認します。高速カットでは境界がキーフレームへ調整されます。保存すると元動画は「（編集前）」として残り、新しい動画が元の名前になります。
  5. 「ファイルの暗号化を戻す…」で通常動画へ戻せます。複数ファイル、フォルダ単位でも操作できます。
  6. Googleからサインアウトすると、保護動画は再生できなくなります。別アカウントでも元の鍵は取得できません。

Google認証と鍵取得にはインターネット接続が必要です。通常のDriveファイルを読む権限は要求せず、動画本体をGoogleや提供者へ送信しません。

このページは操作確認用資料です。App Storeへの審査提出・承認・一般公開が完了したことを示すものではありません。
